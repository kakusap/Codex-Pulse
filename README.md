# Codex Pulse

当前版本：**V0.4.2 独立账号与用量版**。双击 `CodexPulse.exe` 运行，使用 Windows 自带的 .NET Framework、WPF 和 SQLite。

## 账号与额度

从账号明细弹窗的“账号管理 / 添加账号”或“设置 → 账号管理”进入。支持浏览器登录、设备码登录、取消登录、重新登录所选账号、移除本地账号、刷新全部额度、保存账号目录及恢复上次切换前配置。登录与额度查询使用本机 Codex 附带的运行时。

账号目录留空时使用 `CODEX_HOME` 或当前用户的 `.codex` 目录。账号按工作区和用户标识去重；重新登录不同账号不会替换所选账号。移除仅删除看板内的账号记录和凭据。

每 5 秒更新本地显示，默认每 180 秒查询各账号额度；F5 或“刷新全部额度”可手动查询。保留服务返回的窗口长度、重置时间和最近成功快照，区分登录失效、网络失败、限流和无权限。查询失败保留旧快照并显示原因。

悬浮条的 5 小时和 7 天圆环分别显示同周期账号剩余百分比的等权平均。缺少快照、比例无效或周期不同的账号不参与对应平均；全部不可用时显示“—”。重置时间已过仍保留旧快照并标注待更新。该平均值不代表绝对 Token 总量。

点击账号框查看全部账号；点击周期框查看对应额度和重置详情，再次点击收起。账号明细中的“切换并重启 Codex”会验证登录与配置、保存加密备份、应用所选账号，再重启目标 Codex 桌面程序并确认账号。重启失败可重新应用重试。该操作会中断 Codex 进行中的任务。

## 桌面与设置

默认显示 560×56 的悬浮条，拖动后在所在显示器顶部居中吸附，保存显示器选择、宽度和展开高度。显示器断开时回到主屏。点击五小时额度，在详情弹窗右上角点击刷新图标即可更新额度快照；刷新期间图标持续旋转并禁止重复点击。点击“⋯”直接展开或收起用量与热力图；展开后的右下角齿轮可打开设置。

支持四套莫兰迪主题、背景逐像素半透明、置顶与鼠标穿透。穿透状态下悬浮条按钮仍可操作，热力图保留悬浮提示。双击托盘图标恢复操作，托盘菜单可恢复穿透。系统关闭请求收起到托盘，真正退出使用托盘菜单“退出”。

设置支持开机启动、鼠标穿透、主题、背景不透明度、账号管理、Codex 桌面程序路径和可选模型价格表。程序路径留空自动查找；手动配置时选择桌面启动程序，不要选择 `resources/codex.exe`。对话框和标题栏跟随主题，保留无彩色外框的样式。

开机启动使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中 `CodexPulse` 项，无需管理员权限。程序目录移动后请重新保存开机启动设置。

## Token 用量与热力图

展开详情后固定显示官方账号用量与热力图，右上角可筛选对应账号，并保存选择。详情中不再提供本机记录或迁移历史入口。

| 来源 | 范围 | 日期与费用 |
| --- | --- | --- |
| 官方账号 | 各独立账号通过 `account/usage/read` 返回的累计及每日用量；默认每 5 分钟查询，F5 强制刷新 | 按官方返回日期显示，接口未披露日期时区；未提供费用 |
| 本机记录 | 当前账号目录的 `sessions`、`archived_sessions` 中保留的 Token 记录；每 15 秒增量采集 | 北京时间归日；可按自定义价格表估算参考费用 |

原先选中的本机记录或迁移历史会自动改为官方账号。官方累计可能覆盖不同于每日活动的范围，缺少累计时只合计已返回的每日记录。空值、不支持、查询失败均保留可用快照并标注，不把未知当作零，也不自动切换到本机记录。灰色日期表示没有按日记录，悬停查看精确 Token 和费用可用情况。

本机记录按响应去重，并将旧格式累计计数转为增量；首个累计事件只取本次用量，不把此前累计分配到首次观测日。支持进程重启、文件改名、归档、截断和未完成的末行续采。同线程双格式记录在五分钟写入窗口内按累计区间去重，保留此前只有累计事件的历史。超出窗口或无法关联的日志不能保证覆盖完整历史；本机统计不是全设备账单。目录、文件和单轮采集设有大小限制，尚未完成时会继续采集。

只有日志中的明确工作区和用户标识与已知账号匹配时才归属该账号；其余归入“未归属账号”，不会套用当前登录账号。数据库保存统计事件与读取位置，不保存提示词、原始会话或原始日志行。关闭采集后仍可查看已保存记录。

程序默认内置 27 个常用模型的官方 API 参考价格，版本为 `OpenAI-Standard-2026-10-31`，无需填写 JSON 路径。通过“设置 → 查看内置价格表”查看输入、缓存读取、默认缓存写入和输出单价、核对日期与官方来源；窗口跟随主题。内置数据嵌入 EXE，离线可用，随程序版本更新。具体来源见 [内置价格来源](模型价格来源.md)。

参考费用按 Standard API 单价和默认 30 分钟缓存估算，不含 Fast、Ultrafast、区域、工具或其他服务附加费用，也不代表订阅实际付款。适用模型超过 272,000 输入 Token 时按官方长上下文规则调整。缓存写入是独立输入分类，不重复计入普通输入。缺少缓存写入明细时，不把它猜成零；升级后会从仍存在的原日志补齐该字段，保留已有事件标识和 Token 统计。

官方账号接口只返回累计和按日总 Token，未提供逐模型输入、缓存、输出明细。V0.4.2 在同一面板中独立显示“本机参考费用”：根据本机保留的逐条明细及内置或自定义价格表计算，不把官方总 Token 乘以某个单价，也不套用当前模型。上方累计和热力图继续显示官方数据；本机费用的范围与官方累计不同。

费用下方显示已计价 / 全部记录数，并标注是否包含未归属记录。部分记录缺少价格或必要字段时，保留已知金额并显示“（部分）”，未计价金额不视为零。点击金额可查看各模型金额、日期范围、Token 覆盖、价格版本及未计价原因；穿透模式下也可点击。全部账号时包括全部本机记录及未归属记录；筛选账号时仅统计可靠归属该账号的本机记录，未归属记录不计入该账号。没有可计价记录时显示“—”并提供原因。已暂停采集时仍可显示保存的统计结果。

如需覆盖内置表，可在设置中选择自定义 JSON，或沿用账号库目录中的 `model-prices.json`。优先级为：明确选择的文件、账号库目录文件、内置表。自定义表不可读或无效时不会静默换用另一套价格。表内需有 `Version` 和 `Models`；模型名必须精确匹配，单位为美元 / 百万 Token。下面的 `null` 是待填值，必须替换成自己确认的非负价格：

```json
{
  "Version": "自定义价格版本与日期",
  "Models": [{
    "Model": "日志中的准确模型名",
    "InputPerMillion": null,
    "CachedInputPerMillion": null,
    "OutputPerMillion": null,
    "CacheWritePerMillion": null
  }]
}
```

前三项单价必须填写；有缓存写入的模型还需填写 `CacheWritePerMillion`。可用 `LongContextThreshold`、`LongInputMultiplier`、`LongOutputMultiplier` 配置长上下文阈值及倍率。推理输出不重复加到输出上。未公布价格的模型、未知别名或缺少必要用量字段的记录会列入未计价项，不伪装成零费用。价格表是核对日的参考快照，不能用来恢复历史账单，也不能将订阅剩余百分比换算为绝对剩余 Token。

## 数据与兼容

已有独立账号、加密凭据和本地历史用量继续保存在 `data/pulse.db`。V0.4 自动将数据库结构从版本 2 升为 3，新增官方快照、每日用量和本机增量记录表，保留已有账号及历史表。首次升级前应同时备份程序、设置与数据库；需要回退 V0.3 时恢复这三者，旧程序无法读取结构版本 3。

旧设置文件可以直接加载，界面偏好、账号库路径和历史来源选择会保留。保存时不再写入旧外部连接字段。新旧安装均直接使用独立账号，无需切换数据模式。旧数据库中的历史表不删除，也不再提供导入、接管或兼容模式入口。

账号凭据使用当前 Windows 用户 DPAPI 加密。查询环境只获得访问凭据；当前 Codex 使用的账号由 Codex 续期，Pulse 同步其文件结果，其他账号由官方运行时在串行锁内续期。无法确认系统或内存凭据归属时提示重新登录。临时凭据目录限制为当前 Windows 用户访问，操作结束后清理，不记录原始凭据或原始 RPC 错误。

账号切换的配置与登录备份保存为加密文件，失败时恢复本次已修改文件，保留其他程序的并发更新。配置恢复按钮恢复上次切换前备份，重新启动 Codex 后生效。

## 构建与验证

Windows PowerShell 执行 `./build.ps1` 构建；`-OutputDirectory path` 可输出到独立目录。

- `./tests/verify-v03.ps1`：隔离测试登录、查询、续期、缓存、配置事务、账号切换、旧设置兼容、历史保留与清理后的设置界面。`-ProbeRuntime` 额外检查本机运行时。
- `./tests/verify-v04.ps1`：验证结构升级、官方快照与空值、本机去重与续采、累计计数重置、日期边界、账号归属、UTF-8 末行、事务回滚、价格表及界面。`-Live` 额外复制账号库到隔离目录，用只含访问凭据的工作环境查询真实用量；不续期复制的凭据，不改当前登录，不重启 Codex。
- `./tests/verify-account-switch.ps1`：验证重复点击、失败恢复、账号按钮、模拟桌面重启及路径隔离，不切换真实账号。
- `./tests/verify-dialog-theme.ps1`：检查四套主题的标题栏、输入框、列表、选中态及八个账号操作按钮的提示。
- `./tests/verify-clickthrough.ps1`：验证穿透命中、三个用量来源按钮、悬浮详情、热力图提示、多屏定位及托盘行为。
- `CodexPulse.exe --smoke-test`：在隔离安装目录执行桌面布局、设置、主题及托盘冒烟检查。

命令行支持 `--settings path`、`--pulse-db path`、`--codex-home path`、`--inspect output.json`、`--refresh-independent report.json`、`--check-independent report.json` 和 `--probe-runtime report-directory`。检查与查询输出可能包含账号标签，请按个人数据保管。
