# Codex Pulse 独立版实施状态

当前交付为 V0.4.0 独立账号与用量版，使用本机 Codex 运行时执行登录、额度查询、官方用量、凭据续期和账号切换。运行时协议检查与隔离测试工具保留。

已完成：

- 浏览器与设备码登录、取消登录、重新登录、账号去重和本地移除。
- 多账号额度查询、失败保留旧快照、限流退避、凭据续期与当前登录同步。
- 账号切换、加密配置备份、失败恢复、并发文件修改保护和桌面重启路径隔离。
- 悬浮条、账户明细、额度圆环、多显示器定位、四套主题、置顶、穿透、托盘和开机启动。
- 清理废弃外部接入代码、迁移表单、数据模式切换和相关设置；旧设置及独立账号库兼容。

V0.4 已完成：

- 官方账号、本机记录、迁移历史三个独立来源及账号筛选，不相加。
- 官方用量累计与每日快照、空值和失败缓存、五分钟查询间隔。
- 本机增量采集、累计转增量、去重、文件续采与北京时间归日。
- 可靠账号归属与“未归属账号”，不根据当前登录推测历史归属。
- 可选、带版本的精确模型价格表；未知费用显示 —，订阅比例不换算为绝对 Token。
- 结构版本 2 升为 3，保留账号和历史；主题、无彩色外框、穿透与多屏行为延续。

范围限制：官方累计与每日数据由服务决定；本机仅覆盖保留日志，双格式关联使用五分钟写入窗口，不承诺全设备账单。价格表由用户维护。真实到期续期与桌面切换的长期稳定性仍属于后续发布验收。

后续发布阶段：补充真实用户登录与到期续期的长期验收、安装和升级体验。测试中的完整切换及重启使用隔离账号与模拟桌面程序，避免中断当前聊天。
