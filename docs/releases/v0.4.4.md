# Codex Pulse v0.4.4 · 应用内版本更新

发布日期：2026-11-02。适用于 Windows x64 / .NET Framework 4.8。

## 新增

- 设置和托盘菜单增加“检查更新”，显示当前版本、最新稳定版和发布说明。
- 默认启动后检查 GitHub 最新稳定版，运行期间每 24 小时检查一次；有新版本时通过托盘提示，可在设置中关闭自动检查。网络不可用时后台检查保持安静，手动检查提供重试和发布页入口。
- 用户点击“下载并重启更新”后下载 Windows x64 包，显示进度并支持取消。校验 SHA256、发布来源和程序集版本后，等待旧程序退出，再替换原目录中的程序和图标并重启。
- 替换失败时恢复原程序。程序目录不可写、GitHub 限流、下载损坏或账号操作尚未完成时提供明确说明。
- 账号、设置和数据库保持原路径，更新不会替换 `data` 目录；开机启动与快捷方式继续指向原程序。

## 已安装用户如何升级

**v0.4.3 及更早版本没有更新功能，需要手动升级这一次。** 从托盘菜单退出旧版，将发布包中的 `CodexPulse.exe` 和 `pulse.ico` 覆盖到原程序目录，保留原 `data` 文件夹，然后启动。此后可在设置或托盘菜单中更新到后续版本。

更新检查访问本项目公开 GitHub Release，不携带账号凭据、账号目录或用量数据。下载渠道为本项目的 GitHub 附件，网络无法访问 GitHub 时可从发布页手动下载。

## 验证

隔离回归覆盖版本比较、正式版筛选、来源限制、校验文件缺失与重复、ZIP 路径穿越、程序集版本校验、文件替换回滚、设置和数据库保留、辅助进程等待旧程序退出，以及原路径重启与中文参数传递。真实 GitHub 发布包完成下载和 SHA256 校验测试，未安装该测试包。

原有账号、用量、切换与多显示器回归通过。新增更新窗口通过普通窗口层级、按钮状态和渲染检查。原生标题栏像素与跨进程桌面命中检查在本次执行环境分别遇到黑屏和命中异常，旧版复测同样复现，这两项未计为通过。
