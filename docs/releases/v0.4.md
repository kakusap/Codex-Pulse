# Codex Pulse V0.4.2 · 独立账号与用量

本版增加官方 Token 用量、本机增量记录和每日热力图。原有账号管理、切换并重启、额度圆环、主题、置顶穿透、托盘和多屏功能保留。

V0.4.1 默认内置 27 个常用模型的官方 Standard API 参考价格，核对日期为 2026-10-31。设置中点击“查看内置价格表”可直接查看，无需手动选择 JSON。支持自定义覆盖、缓存读写分类、长上下文调整；未知模型仍不套价。官方用量缺少逐模型输入输出拆分时不推算金额，API 等值参考不代表订阅实际付款。来源和范围见 [模型价格来源](../pricing-sources.md)。

V0.4.2 接通面板“本机参考费用”。官方累计 Token 和热力图仍使用官方来源，费用单独使用本机逐条明细。已知价格部分显示金额和覆盖条数；未计价部分标明“（部分）”，点击金额查看模型、时间范围、覆盖 Token、价格版本与未计价原因。账号筛选只带入已可靠归属的记录，未归属记录不会套用到当前账号；全部账号可查看所有本机记录合计。此前因单条未知记录而隐藏已知金额的问题已修复。

## 使用入口

从悬浮条“⋯”展开用量与账户详情，右侧可筛选官方账号。当前界面仅显示官方用量，不提供本机或迁移历史切换。F5 强制刷新；正常官方用量每五分钟更新。内置价格表可在设置中查看，额外价格文件只用于覆盖默认参考单价。

官方没有返回数据时会明确说明，并保留已有快照。本机记录只归属可可靠识别的账号，否则显示“未归属账号”。灰色日期表示没有按日记录，不等于零消耗。设置中可暂停本机采集，也可选择带版本的模型价格表；未配置或缺少模型价格时费用显示 —。

## 数据口径

- 官方累计与每日活动范围可能不同；日期沿用服务返回值，未假定其时区。
- 本机按北京时间归日，保存读取位置和去重事件；同线程双格式记录在五分钟写入窗口内消除重叠。
- 首个累计事件只取本次用量，不把缺失历史记到首次观测日。本机仅反映保留日志，不能作为全部设备的账单。
- 迁移历史保留原密钥统计和限额，不与独立用量相加，也不代表当前订阅余额。
- 参考费用按准确模型名和自定义版本计价，不重复累计推理输出；参考费用不代表订阅实际付款。
