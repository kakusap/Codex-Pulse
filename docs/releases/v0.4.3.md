# Codex Pulse v0.4.3 · 详情收起与弹窗层级修复

发布日期：2026-11-02。适用于 Windows x64 / .NET Framework 4.8。

## 修复

- 展开用量或额度详情后，点击应用以外的区域会自动收起；普通模式和鼠标穿透模式均支持。点击状态条按钮、详情弹窗及应用内菜单时保持展开，鼠标移动不会触发收起。
- 置顶仅用于桌面状态条。设置、账号管理、费用明细和价格表窗口使用普通窗口层级，不再继承状态条置顶。设置内打开账号管理时保留正常的父子窗口关系。
- 管理弹窗保留模态交互，关闭后恢复主窗口操作；状态条的置顶和穿透偏好保持。

## 验证

新增跨进程窗口命中和点击处理回归，覆盖外部左键/右键、应用内按钮和额度弹窗、普通/穿透模式，以及管理弹窗的原生置顶状态和模态输入恢复。点击处理验证使用真实命中坐标调用监听器，不向桌面注入鼠标输入。

发布前执行 Core、主题、鼠标穿透和多显示器验证。

## 升级

在托盘菜单选择“退出”，解压 Windows x64 发布包，使用其中的 `CodexPulse.exe` 和 `pulse.ico` 替换原程序目录中的同名文件，再启动程序。保留原 `data` 目录即可继续使用现有账号、设置和用量记录；本次没有数据库结构变更。
